# DrawScript 3D Chrome Extension (Manifest V3)

Turn any free or paid ChatGPT / Claude conversation into a live, animated 3D visual lesson.

## Installation (Chrome / Edge / Brave)

1. Open `chrome://extensions` in your browser.
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** and select this `extension/` folder.

## How to Use

1. Open **https://chatgpt.com** (or **https://claude.ai**).
2. Click **+ Wrap DrawScript Prompt** above the chat input box, type your question (e.g. *"Explain the Pythagorean theorem"*), and press Send.
3. Click **Play in DrawScript 3D** on the reply to animate it right on the page, or **Send to DrawScript App** to open it in the full DrawScript Studio.
